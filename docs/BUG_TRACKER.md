## BUG-028 ✅
### Android | Warehouse | Stage | Сообщения об ошибках входа на английском (не локализованы)
- **Описание:** Приложение склада (узбекский UI) показывает ошибки входа на английском вместо локализованных: wrong-app → «Access denied», неверный пароль → «Phone or password is incorrect», лимит попыток → «Too many requests». Прочий UI локализуется нормально.
- **Шаги:**
  1. Открыть приложение склада.
  2. а) Ввести телефон чужой роли (напр. 900000003) → «Kirish».
     б) Ввести валидный телефон + неверный пароль → «Kirish».
     в) Повторить неверный пароль 5 раз.
- **Ожидаемый результат:** Локализованные (узбекские) сообщения об ошибках.
- **Фактический результат:** Английские «Access denied» / «Phone or password is incorrect» / «Too many requests».
- **Вложение:** _<скриншот экрана входа>_

## BUG-029 ✅
### Android | Driver-TK | Stage | wrong-app и лимит попыток показаны как «Непредвиденная ошибка»
- **Описание:** Приложение перевозчика не распознаёт осмысленные ответы сервера и валит их в generic-ошибку. Подтверждено на 403 wrong-app (чужая роль) и 429 rate-limit (5 неудач входа).
- **Шаги:**
  1. Открыть приложение перевозчика.
  2. а) Ввести телефон чужой роли (склад 900000004) → «Войти».
     б) Ввести валидный телефон + неверный пароль 5 раз.
- **Ожидаемый результат:** Понятные сообщения: «Это приложение не для вашей роли» и «Слишком много попыток, попробуйте позже».
- **Фактический результат:** В обоих случаях — «Непредвиденная ошибка. Попробуйте снова».
- **Вложение:** _<скриншот экрана входа>_

## BUG-030 ✅
### Android | Driver-TK | Stage | Универсальное неверное сообщение на любую ошибку назначения водителя
- **Описание:** На любую ошибку назначения водителя приложение показывает один текст «Заказ не готов к назначению водителя или превышен лимит водителей», не соответствующий реальной причине (неполный комплект / водитель уже на заказе / лимит достигнут). Функционально назначение работает.
- **Шаги:**
  1. Заказ с `driversCount=2` (SELECTED/IN_WORK).
  2. Спровоцировать ошибку: назначить 1 из 2 / выбрать уже назначенного водителя / добавить сверх лимита.
- **Ожидаемый результат:** Сообщение под конкретную причину.
- **Фактический результат:** Всегда «Заказ не готов к назначению водителя или превышен лимит водителей».
- **Вложение:** _<скриншот экрана назначения водителя>_

## BUG-031 ✅
### Android | Driver-TK | Stage | При замене водителя в списке показан уже назначенный на этот заказ
- **Описание:** На заказе с 2 водителями при замене одного экран «Назначить водителя» показывает как кандидата второго, уже назначенного на этот же заказ. Выбрать его нельзя (будет «водитель уже прикреплён»).
- **Шаги:**
  1. Заказ с `driversCount=2`, оба водителя назначены.
  2. Нажать «Заменить» (карандаш) у одного водителя.
  3. Посмотреть список кандидатов.
- **Ожидаемый результат:** В списке — свободные + текущий; второй водитель этого заказа исключён.
- **Фактический результат:** В списке присутствует второй, уже назначенный на этот заказ водитель.
- **Вложение:** _<скриншоты «Детали груза» + «Назначить водителя»>_

## BUG-033 ✅
### Android | Driver-TK | Stage | Нет подтверждения при выходе из аккаунта
- **Описание:** «Chiqish» (Выход) выполняет выход сразу по тапу, без диалога подтверждения — риск случайного выхода.
- **Шаги:**
  1. Войти перевозчиком, открыть профиль.
  2. Нажать «Chiqish».
- **Ожидаемый результат:** Диалог «Вы точно хотите выйти из аккаунта?» → выход после подтверждения.
- **Фактический результат:** Мгновенный выход без подтверждения.
- **Вложение:** _<скриншот профиля>_

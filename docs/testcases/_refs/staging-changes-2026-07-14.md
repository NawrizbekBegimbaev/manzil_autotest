# Изменения staging (билд de507b20, 2026-07-14) — для актуализации Web тест-кейсов

Наблюдения получены при живом QA серии рефакторингов FSD + W3.1–W3.7 + dead-code на
`staging-manzil.greatmall.uz`. Это ФАКТЫ с реального билда — по ним правим Web-книгу.
Backend в этих MR почти не менялся → API-книга и Mobile-книга актуальны, трогаем только Web.

## Язык / вход / оболочка
- **Свежая сессия открывается на КИТАЙСКОМ** (`DEFAULT_LANGUAGE='zh'`, China-first — ЗАДУМАНО,
  не баг). Логин-плейсхолдеры `请输入电话号码` / `请输入密码`, кнопка `登录`, телефон дефолт +86.
  Автоопределение языка по браузеру/стране ОТКЛЮЧЕНО. Кейсы про «дефолтный язык = русский/узбекский»
  — УСТАРЕЛИ, поправить на «первый вход = zh; выбор языка сохраняется в localStorage».
- Язык хранится в localStorage под ключом `__tolgee_currentLanguage` (Tolgee). 5 языков: ru/uz/ky/zh/ug.
  Казахского НЕТ.
- Роли во фронте схлопнуты: SHIPPER_MANAGER/OPERATOR/DISPATCHER → «MANAGER», различаются по
  effectiveCapabilities из /me. SHIPPER_ADMIN → ADMIN.
- Гварды: `ensureRole` + `canAccess(role,capabilities,path)`; менеджер без REPORTS на /dashboard,/reports —
  НЕ видит 403, а РЕДИРЕКТ на домашний маршрут (пункт меню скрыт). 403 живёт только на API.
- Панель настроек (шестерёнка в топбаре, компонент «Settings»): тумблеры **Mode** (тёмная/светлая),
  **Contrast**, **Right to left**, **Compact**, выбор Layout (3) и Color (Integrate/Apparent).
  ⚠ Подписи панели — АНГЛИЙСКИЕ (Mode/Contrast/...) при любом языке UI. Смена Mode применяется и
  СОХРАНЯЕТСЯ после reload (фон rgb(255,255,255)↔rgb(20,26,33)). RTL для уйгурского вручную, не авто.
- Приветственный тост «Добро пожаловать …» захардкожен по-русски (не через t()).

## Таблицы (W3.1–W3.4) — единый механизм фильтров/меню
- **Состояние фильтров в URL**: вкладка статуса → `?tab=…`, поиск → `&search=…`, страница → `&page=…`.
  Переживает перезагрузку. Кейсы про фильтры/поиск/вкладки — добавить проверку URL-состояния + reload.
- **Смена фильтра/вкладки сбрасывает пагинацию на первую** (page-параметр уходит). Добавить такие кейсы.
- **Панель «Фильтры»** (draft-состояние): ввод применяется по **Enter** ИЛИ кнопке **«Поиск»**; есть
  **чипы активных фильтров** (подпись, напр. «Номер заказа: NAMA-00003», «30.06.2026 – 30.06.2026»),
  снятие чипа крестиком, кнопка «Очистить». Даты — границы ВКЛЮЧИТЕЛЬНЫЕ (loadFrom=loadTo=дата → строки этой даты).
- **Меню действий строки (RowActionsMenu)**: единое во всех таблицах; пункты «Редактировать»/«Удалить» +
  спец-пункты (Отменить заказ, Заведён в 1С, связь и т.п.), статус-зависимые. Клик по меню НЕ навигирует
  строку (stopPropagation). В headless меню открывается фокус+Enter на ⋮, обычный клик грид глотает.
- Списки на MUI DataGrid: readiness-локатор `[role=grid]`, поиск под «Фильтры», размеры страницы 10/25/50.

## Формы (W3.5) — общий пароль + CRUD
- 5 форм: сотрудник, самозанятый водитель, компания-грузоотправитель, транспортная компания (с паролем),
  водитель ТК (без пароля). Пароль-поле общее: 2 поля (пароль + подтверждение/сверка), показ/скрытие «глаз».
  Схема: мин. 8, заглавная+строчная+цифра+спецсимвол. Несовпадение → ошибка, сохранение блокируется.
- **Редактирование сотрудника без смены пароля допустимо** (поля пароля пусты, «Сохранить» активна).
- Сохранение → тост успеха + список обновляется (общий CRUD-хук). Плейсхолдер телефона в форме
  водителя — «Enter phone number» (англ., мелкая i18n-недоработка).

## Справочники CN/KG (W3.6) — раздел «Города» (/super-admin/cities)
- ⚠ Дивизионы CN/KG живут в разделе **«Города»** (не отдельные страницы). Переключатель — дропдаун
  **«Страна»**: China / Karakalpakstan / Kyrgyzstan / Uzbekistan (не вкладки!).
- **CN** (Китай): «Всего: 42053», колонки **Название / Пиньинь / Уровень / Путь / Действия**. Поиск по пиньинь
  (напр. «shang» → 389). Пагинация ~1683 стр. Уровни: Провинция/Город/Район/Посёлок.
- **KG** (Кыргызстан): «Всего: 62», колонки **Название (рус) / Название (англ) / Название (кырг) / Уровень /
  Область / Код**. Без пиньинь.
- Редактирование деления: **Код и Уровень (позиция в иерархии) ЗАБЛОКИРОВАНЫ** (серые/disabled); у CN
  редактируется Название + **Пиньинь**, у KG — три названия. Показано Родительское деление.
- Создание («Новое административное деление»): выбор **Родительского деления** (поиск), Уровень, для CN — Пиньинь.
- Редактирование инлайн-карандашом в колонке «Действия» (не ⋮-меню).

## Детали партнёров + чип связи (W3.7)
- Карточки деталей (перевозчик/грузоотправитель/водитель, страница `$id`) построены общим **DetailItem**
  (пара «подпись + значение»). У перевозчика спецконтент: чип «Типы транспорта» (напр. «Автомобильный»),
  «Чёрный список складов», «Принимать все направления».
- **CommunicationStatusChip** (статус связи) в 4 поверхностях: список заказов, склад, связь, шапка карточки
  заказа. Подписи: «Связаться» (оранжевый), «Подтверждён» и др. — для заказов «в работе».

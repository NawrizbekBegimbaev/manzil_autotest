# Живые наблюдения — Приложение ТК/перевозчика (carrier) Manzil

Пакет `uz.logos.manzil.driver` (это и есть приложение ТРАНСПОРТНОЙ КОМПАНИИ, роль TRANSPORT_ADMIN,
clientType=TRANSPORT_COMPANY_APP). Версия в подвале профиля: «Manzil-TC v1.0 · Build 2026.05».
Снято 2026-07-13 на staging (staging-manzil.greatmall.uz), эмулятор Pixel 6 / Android 14. UI узбекский.
Вход выполнен под ТК: `+998900000002 / <staging-password>` → 200. Прошёл ВСЕ экраны вживую.

## Вход (экран «Yana xush kelibsiz»)
- Верх слева: язык «🌐 O'zbekcha ⌄».
- Логотип: синий кружок «M» + «Manzil».
- Заголовок «Yana xush kelibsiz», подзаголовок про грузы и маршруты.
- Поле «Telefon raqam» (лейбл сверху, зелёная точка): флаг + «+998 ⌄», плейсхолдер «00 000 00 00», 9 цифр.
- Поле «Parol»: замок слева, крестик-очистка + глаз-показать справа.
- Кнопка «Kirish →» — неактивна при пустых полях.
- Согласие «Kirib, siz Foydalanish shartlariga rozilik bildirasiz».
- Клавиатура предлагает автозаполнение номеров.
- Ответы сервера (логи OkHttp): успех → 200 /auth/login + 200 /me; чужая роль (SHIPPER_MANAGER) → 403 wrong-app;
  неверный пароль → 401 error.invalid-credentials.

## Главный экран «Mavjud yuklar» (доступные грузы) — вкладка Buyurtmalar
- Заголовок «Mavjud yuklar».
- Поиск: «Marshrut, TC, ID bo'yicha qidirish...» (по маршруту, ТК, ID).
- Карточка груза: слева синяя точка + номер (NAMA-00011, UEIE-00026/25/24 — РАЗНЫЕ префиксы),
  справа бейдж «Avto» (тип транспорта). Строка маршрута: город отправления → стрелка → город назначения.
  Низ карточки: дата (2026-07-15) + иконка ТС с типом.
- Нижняя навигация: «Buyurtmalar» (грузы, активна), «Takliflar» (предложения), «Profil».
- ⚠ БАГ ЛОКАЛИЗАЦИИ: при узбекском UI тип ТС показан по-китайски «平板 13.7» (Bortli/бортовой),
  город — иероглифами «义乌市» (Yiwu). Смешение uz/ru/zh на одной карточке (义乌市 → г.Ош).

## Детали груза «Yuk tafsilotlari»
- Шапка: номер (NAMA-00011), заголовок «Yuk tafsilotlari», колокольчик-уведомления, стрелка назад.
- Карточка маршрута откуда→куда.
- Секция «Yuk spetsifikatsiyasi» (спецификация груза):
  - «Transport»: 平板 13.7 (тип ТС; ⚠ по-китайски)
  - «Haydovchilar soni» (число водителей): 1
  - «Uzunlik» (длина): 13.7 m
  - «Yuklash sanasi» (дата загрузки): 2026-07-15
  - «To'lov turi» (тип оплаты): CNY
- Кнопка внизу: «Taklif yuborish» (отправить предложение).

## Форма оффера «Taklif yuborish»
- Шапка: номер груза, «Taklif yuborish».
- Карточка маршрута.
- «Sizning taklifingiz» (ваше предложение) — поле цены с префиксом ¥ (валюта CNY), числовая клавиатура, обязательное.
- «Yuklash sanasi» — дата загрузки, readonly (серая, 2026-07-15).
- «Dispetcher uchun izoh» (комментарий для диспетчера) — текстовая область, необязательное.
- Кнопки: «Bekor qilish» (отмена) / «Yuborish» (отправить) — «Yuborish» неактивна, пока не введена цена.

## Вкладка «Takliflar» (мои предложения)
- Вкладки статусов со счётчиками: «Yangi» (новые), «Tanlangan» (выбранные), «Jarayonda» (в процессе),
  «Yo'lda» (в пути) — горизонтально прокручиваемые. У тест-аккаунта: Yangi 0, Tanlangan 0, Jarayonda 4.
- Сначала показываются СКЕЛЕТОНЫ загрузки, затем — контент или пустое состояние.
- Пустое состояние (вкладка Yangi): карточка с пунктирной рамкой, иконка-конверт, «Faol takliflar yo'q»
  (нет активных предложений), подсказка «Yukni oching va taklif yuboring — bu yerda paydo bo'ladi».

## Профиль (Profil)
- Карточка-шапка: метка «TRANSPORT KOMPANIYASI», ФИО «Begimbaev Naurizbek Mambet…», компания «Naurizbek Trucks»,
  аватар «BN».
- Три плитки статистики: «472 mavjud» (доступно), «187 kutilmoqda» (ожидается), «1 jarayonda» (в процессе).
- Пункты меню: «Bildirishnomalar» (уведомления, красный бейдж «2»), «Til» (язык, «O'zbekcha»),
  «Avtopark» (автопарк, значение «7 haydovchi»).
- Кнопка «Chiqish» (выход, красная).
- Подвал: «Manzil-TC v1.0 · Build 2026.05».

## Автопарк «Avtopark» (управление водителями)
- Шапка «Avtopark», стрелка назад.
- Поиск: «F.I.O., raqam, tel bo'yicha qidirish...» (по ФИО, номеру, телефону).
- Список карточек водителей: аватар (инициалы), имя, код «NAMA-xxxxx», телефон, справа КРАСНАЯ корзина (удалить).
  Примеры: cxzvxz / NAMA-00007 / +8635123512312 (китайский номер); FASD / NAMA-00007 / +998900051235;
  Alo alo / NAMA-00005; Zivertillo / NAMA-00008; Zivert / NAMA-00003; Begimbaev Naurizbek / NAMA-00003.
  ⚠ Коды повторяются (NAMA-00007 дважды, NAMA-00003 дважды) — проверить, что это за код и норм ли дубли.
- Кнопка внизу: «+ Haydovchi qo'shish» (добавить водителя).

## Форма добавления водителя «Yangi haydovchi»
- Поля: «To'liq ism» (полное имя), «Telefon raqam» (+998, 9 цифр), «ID karta raqami» (номер ID-карты).
- Кнопки: «Bekor qilish» (отмена) / «Saqlash» (сохранить).

## Серверная привязка (для сшивки кейсов)
Backend перевозчика уже разобран в docs/testcases/api/04_tendering_transport.json:
лента /transport/feed (фильтр по обслуживаемым городам, isAll, ЧС складов; БЕЗ фильтра по типу ТС),
подача оффера (not-open-for-bids, already-submitted, offer.not-editable, carrier-excluded),
водители CRUD (phone-exists, busy-cannot-delete, card-id-required), назначение (busy-on-another-order,
blacklisted, plate-busy, drivers-incomplete, not-owned-by-transport→404). Оплата CNY по умолчанию.

## Найденные дефекты (оформить кейсами ⚠)
1. Локализация: тип ТС «平板» и город «义乌市» по-китайски при узбекском UI (несколько экранов: карточка ленты, детали).
2. Дубли кодов водителей NAMA-xxxxx в автопарке — проверить семантику кода.
3. Удаление водителя — красная корзина прямо в списке; проверить наличие диалога подтверждения (риск случайного удаления).
4. Китайский/некорректный телефон водителя (+8635123512312) в списке — проверить валидацию телефона при добавлении.
